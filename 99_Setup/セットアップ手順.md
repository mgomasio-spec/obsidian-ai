# セットアップ手順

## 1. 保管庫を置く（iPhone＋Macで無料同期する場合）
1. iPhoneとMacにObsidianを入れる（無料）
2. iPhoneのObsidianで「Create new vault」→ 名前を `AI-Vault`、「Store in iCloud」をオンにして作成
3. いったんObsidianを閉じる
4. 「ファイル」アプリで `AI-Vault.zip` をタップして展開し、中身を `iCloud Drive/Obsidian/AI-Vault/` に上書きコピー
5. MacのObsidianで「Open folder as vault」→ `iCloud Drive/Obsidian/AI-Vault` を選ぶ
6. 「Trust author and enable plugins」が出たら許可する

> 同期が不安定なら、公式のObsidian Sync（年払いで月$4）に切り替える。

## 2. Claudeから読み書きする（追加料金なし・Mac）
Claude Desktopの 設定 → 開発者 → 設定を編集 で `claude_desktop_config.json` に以下を追加（Node.jsが必要）:

```json
{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/あなたのユーザー名/Library/Mobile Documents/iCloud~md~obsidian/Documents/AI-Vault"
      ]
    }
  }
}
```
Claude Desktopを再起動 →「AI-VaultのAGENTS.mdを読んで、今日のデイリーノートを作って」などと頼む。

Claude Codeを使う場合は、保管庫フォルダで `claude` を起動するだけ（`CLAUDE.md` が自動で読まれる）。

## 3. Obsidianの中でAIを使う（Copilot for Obsidian）
1. 設定 → コミュニティプラグイン → 制限モードをオフ → 閲覧 →「Copilot」をインストールして有効化
2. 設定 → Copilot → Basic → Set Keys でAPIキーを入れる（Gemini APIなら無料枠あり）
3. 右サイドバーのCopilotで「Vault QA」モードにすると、保管庫全体に質問できる

## 4. 自作アプリから書き込む
`tools/vault_writer.py` を使う。

```python
from vault_writer import write_output
write_output(VAULT, source="jev", title="朝の判定",
             body="傘：必要\n重要メール：1件", project="JEV判定アプリ")
```

**どこで動くアプリかで書き込み方が変わる：**
- **Mac上で動くスクリプト**：保管庫のパスを指定して直接書き込める
- **Pythonista（iPhone）**：「Open External Folder」で保管庫フォルダを開けば直接書き込める
- **Railwayなどのサーバー**：iCloudには直接書けない。GitHubのリポジトリを経由させる。
  - サーバー → GitHubのリポジトリにMarkdownをコミット
  - Obsidian側はコミュニティプラグイン「Git」で定期的にpullする
