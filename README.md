# AI-Vault へようこそ

人間（こまさん）と複数のAIが同じメモを読み書きするための保管庫です。

## フォルダ構成
| フォルダ | 用途 | 誰が書く |
|---|---|---|
| `00_Inbox/` | とりあえずのメモ・思いつき | 人間・AI |
| `10_Projects/` | プロジェクトごとのノート | 人間（AIは追記のみ） |
| `20_AI-Output/` | AIやアプリが書き出す結果・ログ | AI・自作アプリ |
| `30_Daily/` | デイリーノート | 人間 |
| `90_Templates/` | テンプレート | 人間 |
| `99_Setup/` | セットアップ手順 | — |
| `tools/` | アプリから書き込むためのスクリプト | — |

## AIへのルール
[[AGENTS]] に書いてあります。どのAIにも最初にこれを読ませてください。
